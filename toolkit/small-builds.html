## Meeting ideas

(the transcript text)

The format transcribe.py --save writes, from the voice-transcriber readme.

What you get

  • Page-saving extension is a Chrome extension that saves a web page as an AI-written note in a GitHub repo (a project folder with a saved history) or a Notion database.
  • Voice transcriber is a local Whisper transcriber for voice notes in 99 languages. It writes a markdown note. It needs no internet after the one-time model download.

Builds on: Readability.js by Arc90 and the Mozilla contributors (Apache 2.0), inside the page-saving extension. Notices in the repo.

Copy it

Time to set up: 10 to 20 minutes each. Pick the assistant you use. The choice is remembered on this device.

The voice transcriber runs in a terminal on an Apple Silicon Mac.

Set up and run the transcriber
[ -d ~/how-i-work ] || git clone https://github.com/DanielErCohen/how-i-work.git ~/how-i-work
cd ~/how-i-work/small-builds/voice-transcriber
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
brew install ffmpeg
# Replace voice-note.m4a with the path to your own recording
python3 transcribe.py voice-note.m4a --save

The first run downloads the model once. ffmpeg is required: the transcriber uses it to read every audio file. Replace voice-note.m4a with the path to your own recording. python3 must be an Apple Silicon build. Check with python3 -c "import platform; print(platform.machine())", which prints arm64.

Neither tool needs Claude to run. Open the link, copy the readme text and follow its steps in a terminal.

Setup steps

  1. Voice transcriber: clone how-i-work, then on an Apple Silicon Mac follow the setup in the readme: a virtual environment, pip install -r requirements.txt, brew install ffmpeg and the one-time model download (10 minutes).
  2. Page-saving extension: create a private GitHub repo for captures (notes land in 02-areas/saved-articles) and a fine-grained token, then open chrome://extensions, turn on Developer mode, choose Load unpacked and select the extension folder. The readme has every step (15 to 20 minutes).

Why I use it

Each one covers a task where I could not find a tool that fit. Each has one job and few files. Neither needs a server. Building them also showed me what a non-coder can ship with agents (separate Claude helpers, each on one task).

Came from

These did not come from one of the five projects. Each solved a task of mine: saving what I read and turning voice notes into text. The products themselves are on the projects page.
