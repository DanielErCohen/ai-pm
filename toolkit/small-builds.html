What you get

  • Page-saving extension is a Chrome extension that saves a web page as an AI-written note in a GitHub repo or a Notion database.
  • Voice transcriber is a local Whisper transcriber for voice notes in 99 languages. It writes a markdown note. It works offline after the one-time model download.

Builds on: Readability.js by Arc90 and the Mozilla contributors (Apache 2.0), inside the page-saving extension. Notices in the repo.

Copy it

Time to set up: 10 to 20 minutes each. The extension needs an AI API key. The transcriber runs offline on Apple Silicon.

Voice transcriber

It runs in a terminal on an Apple Silicon Mac.

Set up and run the transcriber
[ -d ~/how-i-work ] || git clone https://github.com/DanielErCohen/how-i-work.git ~/how-i-work
cd ~/how-i-work/small-builds/voice-transcriber
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
brew install ffmpeg
# Replace voice-note.m4a with the path to your own recording
python3 transcribe.py voice-note.m4a --save

The first run downloads the model once. ffmpeg reads every audio file. python3 must be an Apple Silicon build. Check with python3 -c "import platform; print(platform.machine())", which prints arm64. The readme has the rest.

Page-saving extension

It loads as an unpacked extension in Chrome.

Get the extension folder
[ -d ~/how-i-work ] || git clone https://github.com/DanielErCohen/how-i-work.git ~/how-i-work
  1. Open chrome://extensions, turn on Developer mode and choose Load unpacked.
  2. Select ~/how-i-work/small-builds/page-saving-extension.
  3. Create a private GitHub repo for captures (notes land in 00-inbox/) and a fine-grained token limited to that one repo. The extension keeps the token in the browser's extension storage in plain text.

The readme has every step (15 to 20 minutes).
