How to use the starter
  1. Download and unzip the pack, then open starter.html in a browser.
  2. Use Copy prompt with the included files and your permitted notes. For a manual start, replace the fields in the complete first-record example near the top of the README.
  3. Save the result as my-review.json and choose Import my JSON in the starter.

Keep that JSON file. The starter opens empty after a reload, so import it again to continue. Editing is easiest on a computer.

What’s in the download?
  • starter.html: an empty version of this demo.
  • Blank and synthetic JSON, a schema and an adaptation prompt.
  • A README, validation checklist and MIT licence.
Read or edit the prompt

Attach starter.html, schema.json, blank-data.json and README.md to your assistant. Replace the brackets before using it.

Evidence, privacy and the existing skill

The records here are synthetic. In your copy, keep observations, interpretations and proposed actions distinct. Review source evidence before changing an assessment or selecting an achievement.

The starter displays imported JSON in browser memory. It does not connect to work systems, upload your notes or save changes. Keep source records and approvals in your existing private files.
