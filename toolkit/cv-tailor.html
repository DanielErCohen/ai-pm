cv-tailor

Build one strong main CV, tailor it to each posting and keep every version.

Why I built itI sent over 100 CVs and got back barely a handful of replies, so I rebuilt my CV for the software that screens it.
  • After the change, about 1 in 5 got a reply.
  • The structure of my CV was hard for that software to read.
  • It used my wording where each posting had its own. One version went to every role.
  • In Harvard Business School's Hidden Workers survey (2021) of employers in the US, UK and Germany, about 6 in 10 used recruitment software. More than 9 in 10 of those let it make the first cut of applicants.
  • I first built this as an app, LandMyCV, to help myself and others find a relevant job. In Apr '26 I paused the app and kept its steps here as plain files that Claude follows.

What you get

Six Claude skills that take you from one main CV to a tailored CV per role.

  • A change log (changes.md) with every tailored CV, listing what changed against the main CV and why. Read it and check every claim before you send.
  • A "read it as them" step before the ATS check: simulated readers (a recruiter screen, HR, the interviewing PMs, the hiring manager) list their objections. In a chat in the Claude app, you run each reader in a new chat with a brief the skill gives you.
  • A formatting check for applicant tracking systems (ATS), the software that screens CVs.
  • Templates for the main CV, an achievements bank and one folder per application.
  • Seven short guides and one fictional worked example.
  • The skills use only the experience and numbers you provide.
  • cv-tailor lives in its own repo.

Copy it

Time to set up: 15 minutes. Pick the assistant you use. The choice is remembered on this device.

Run this in a terminal from any folder. It clones the repo to ~/cv-tailor if you do not have it, copies the six skills and puts the ATS checklist beside cv-review and cv-tailor. The cp -n flag never overwrites a skill you already have. Keep your CV in a private folder or repository.

Setup steps

  1. Get the repo. On GitHub, open cv-tailor, click "Use this template" and choose Private. GitHub does not allow private forks of public repositories, so a template copy is how you keep a private one. Clone it, or download the repository ZIP and extract it into a local folder.
  2. Install the skills: run the block in the Claude Code tab above, or download the six zips and upload each one with the steps in the Claude app tab above.
  3. Tell Claude: "Use cv-intake to build my main CV." Attach your old CV or a LinkedIn export and answer its questions about outcomes and numbers. Save the result as my-cv/main-cv.md.
  4. Tell Claude: "Use cv-review on my main CV." Fix the top items, then commit the version.
  5. Per job: copy applications/_template/, paste the job description and tell Claude: "Use cv-tailor on this application folder."

Try cv-intake

First prompt
Use cv-intake to build my main CV from the material I attached. Ask about missing outcomes or numbers before drafting them.

Expected result: a main CV based on your supplied history and questions for missing evidence; verify every claim before saving it.
