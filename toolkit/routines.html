Setup and support
Why I built itI subscribed to 12 product newsletters and rarely read them, so a routine now reads them for me.
  • The digest arrives Monday and Thursday morning: 4 headlines, one product-sense drill from a 24-topic curriculum and one thing to use this week.
  • A cap on each section keeps a read to about 4 minutes.
  • The routine stores its state in the sent email's footer, so it needs no database.
  • When a source sheet changes, the refresh stops and names the failed check.

What you get

Two routines you can copy.

  • PM digest reads a curated list of newsletters from your inbox twice a week.
    • The digest carries product news and tech news below the headlines.
  • Metrics dashboard refresh pulls spreadsheets, validates them and publishes only the data file.
    • The example parser writes a data file only when its checks pass.
    • Replace those checks with the rules for your data before connecting it to a dashboard.
    • The page reads a published data file. Check that file for private data before publishing it.

Setup steps

  1. PM digest: subscribe to your newsletters, create a Gmail label and a filter that applies it, then copy routine-prompt.md and replace each placeholder in angle brackets.
  2. Create a scheduled routine in Claude Code with the Gmail connector and WebFetch enabled, paste the prompt, and run it once by hand. Fix the prompt until the output reads well (30 to 45 minutes in total).
  3. Metrics dashboard refresh: in ~/how-i-work/routines/metrics-dashboard-refresh, run python3 parse_example.py --input data/sample-open-period.csv --out dist/data.js on the ten fictional sample rows. Exit code 0 means the file was written. Exit code 1 means a check failed and nothing was written. Then replace the schema and checks in parse_example.py with yours and point --input at your export.
  4. Wire it to a schedule with a skill or routine that downloads the sources, runs the parser, publishes the data file only when the exit code is 0 and reports in one line. Keep file IDs and URLs in a private config.
