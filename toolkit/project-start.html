Setup

Project start

A new project with an AI agent leaves open who decides, how work is checked and what waits on you. Claude interviews you once and writes it down: a one-page brief with the results that would make you stop, and a checklist of what waits on you. In Claude Code it also installs only the checks your answers call for.

Used in How I work: step 1 and step 3.

Download for Claude Code ZIP

Copy prompt is for the Claude app. The ZIP is for Claude Code only.

In the Claude app: 1. Copy the prompt. 2. Paste it into a new chat and answer 12 questions, one at a time. 3. Save the brief.md and owner.md it returns in a Claude Project.

Where the stop rule came from: on Parapet no scored round held the 7.5 out of 10 quality line I had set. Instead of stopping, I added a 95% recall line in Sep '26 and then replaced the score with an estimator's timed review. I stopped the product later that month, before the review ran. Here a failed kill line leads to stop, pivot or rescope, never to a new metric.

Limits: a red team and simulated builders (Claude agents playing new project owners) tested it; no second real project has used it yet. Checks and guards enforce only in Claude Code; the Claude app route gives documents only.

project/brief.md

What it is

Rebook is a rebooking assistant for independent hair salons. Each week it finds clients who are overdue for their next visit and sends the salon's own WhatsApp message with two open slots.

Who it is for

  • First user: Owners of salons with one to four chairs who keep bookings on paper or a basic calendar.
  • Evidence: 4 of 6 owners interviewed in Sep '26 named lapsed regulars as their biggest revenue leak. One showed a paper list of 40 clients she meant to call.
  • Evidence stage: reported in interviews, not yet observed

What it does

  1. List the clients past their usual interval each week.
  2. Send the salon's message with two free slots in one tap.
  3. Mark who rebooked.

What it does not do

It does notBecause
Run a booking calendarSalons keep the book they already use.
Take paymentsThe first test needs only a message.
Run marketing campaignsIt follows up on clients the salon already has.
Send a message without the owner tapping sendThe salon stays the sender of every message.

Alternatives

Booking platforms already send reminders. These salons avoid them because of commission and moving their book. Rebook wins only if it works on top of the book they keep.

Beliefs

1Lapsed regulars rebook when their salon messages them personally.Fewer than 15% of the 250 messaged clients (50 per salon) book within 14 days.Proposed, untested
2Owners will enter 50 past clients to start.Fewer than 3 of 5 pilot salons enter 50 clients in their first week.Proposed, untested
3A salon pays EUR 1 per rebooked client once it sees rebookings.Fewer than 2 of 5 pilot salons pay after a 30-day pilot.Proposed, untested

First step

A two-week concierge test with five pilot salons, with messages sent by hand before any code. The riskiest belief is demand, so it is tested first.

project/owner.md

Spend ceiling: EUR 20 a month until a salon pays, set by Lea.

Waiting on you

1. Recruit five pilot salons for the concierge test

It blocks the first test.

  1. Pick five of the six owners you interviewed.
  2. Ask each for their last 50 clients with the date of the last visit.
  3. Agree the message wording with them.

Default: the four owners who named lapsed regulars, plus one more of the six.

Decisions for you

1. Price for the paid pilot: EUR 1 per rebooked client or EUR 19 a month flat?

  • Recommendation: EUR 1 per rebooked client during the pilot, so a salon pays only for results. Belief 3 tests this price.
  • Strongest counter: a per-client price is hard for an owner to predict each month.
  • Default: EUR 1 per rebooked client.
  • Decided by: Lea

Privacy

Personal data is in scope.

  • Client names and phone numbers belong to the salon.
  • Rebook stores them only to send the salon's own messages.
  • They are never pasted into a chat with an AI tool.
  • A salon's data is deleted when it leaves.
  • Each message says which salon sent it.
  • The salon controls its client data. Rebook, and Meta through the WhatsApp Business API, process it for the salon, and both are named in the salon agreement.

Beliefs are what must be true for the project to be worth doing, each with the result that would prove it wrong. Kill lines are the numbers that decide whether to continue, rescope or stop, written before the test.

The project, the person and the answers in this preview are invented. The kickoff interview fills these two files from your own answers.

It brings two other tools into a new project: the interview challenges your answers the way product-sparring does, and the Claude Code setup keeps a dated decision log, the short form of a decision record.

Full setup instructions

How to use
  1. In the Claude app, copy the prompt, paste it into a new chat and answer one question at a time.
  2. Save the brief.md and owner.md it returns in a Claude Project's files or a notes app.
  3. In Claude Code, download the repo and follow Setup and support to install the full setup.

The Claude app route gives you documents only. Guards (small scripts that run on their own at set moments), skills and review agents install in Claude Code.

Read or edit the prompt
Source and limits

The tool is MIT-licensed. A red team (a fresh Claude session that challenges the work) and simulated builders tested it. Simulated means Claude agents played new project owners. It has not yet started a second real project.

At the end of an install, a verify script runs these checks:

  • No leftover placeholder, "ADAPT" note or unmerged copy of one of your files.
  • No absolute home path and no key-shaped string.
  • Markdown links resolve, shell scripts parse and the settings file is valid JSON.
  • The guard hook passes its own tests, and its push setting matches the merge mode you chose.

Then a fresh Claude agent reads the installed project cold and answers five questions about it. Claude fixes the gaps once.

These checks do not judge whether your answers are right. Hooks and permissions enforce only in Claude Code. The installer copies files and uses no network, remote or account. Model names, commands and tools are dated Oct '26, and the install tells Claude to check them on your machine first.

For a team

When more than one person decides, the setup writes down who owns which call.

  • The interview asks who else decides and writes a decision table with a decider per area and a tie-break.
  • It offers four merge modes: solo; Claude merges after checks and review; a person approves; issues only, for a partner who owns the code.
  • An agent review never counts as the human approval.

If Rebook had a second founder, the table in project/working-agreement.md would read:

AreaDeciderNote
Scope, price and anything a salon seesLeaArbiter on a tie
Salon partnerships and the salon agreementSam, cofounderLea signs
Technical choicesClaudeCostly ones go in the decision log

Tie-break: when Lea and Sam disagree, the current state stands and both views go in owner.md. Lea decides. After 7 days without an answer, the default applies and is logged.

Setup and support
Why I built itBuilding projects with Claude, I kept finding out late that no one had written down who decides, how work is checked or what waits on me.
  • On Wellness Coach, the iPhone app I build on weekends, review rounds kept chasing small issues while nothing shipped. The rule is one review round. Anything a person sees is finished in its own change.
  • The owner checklist filled with technical questions. It now holds only what waits on the owner.
  • On Parapet, the B2B tool I stopped in Sep '26, the stop bar moved during the work. Stop lines are now written before the test and logged with a date.
  • The interview sizes the setup, so a weekend project does not inherit a team's process.
  • LEARNINGS.md in the repo lists every failure and where each rule lives.

Set up in Claude Code

The full install runs in Claude Code, because the guards and skills are Claude Code features. It needs git 2.28 or later, and Git Bash on Windows.

Clone the repo outside your project:

Clone the repo
git clone https://github.com/DanielErCohen/project-start.git ~/project-start

Open Claude Code in the cloned folder and paste this line, with <path> set to where you cloned it:

Start the interview
Start a project from <path>/project-start/START.md

Claude installs a small core for every project and adds a module, such as sprints, review or privacy, only when one of your answers calls for it.
